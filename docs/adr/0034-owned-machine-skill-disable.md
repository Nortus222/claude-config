# Machine Off disables only positively owned skill destinations

A machine's explicit Off choice must disable installed skills without erasing local content or changing the shared manifest. The machine service validates a unique declaration, a matching regular installer lock record with an unambiguous native selector, and every known Claude/Codex exposure against the managed shared copy by exact symlink destination or complete tree identity, including entry modes. It backs up the known destinations and raw lock, rechecks ownership, removes only those entries, and atomically removes only that selector's lock entry while retaining all other fields. This narrow exception to installer-owned lock writes avoids the installer's global removal and unknown agent destinations. Deletion failures retain metadata for retry; inherited optional Off preserves prior installations. Native addition verification remains with its existing owner.
