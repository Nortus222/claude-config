# Use manual dispatch as image publication approval

Nortus222 is currently the sole release participant, and the owner removed the redundant image environment approval. Manual `service-image` dispatch for the exact reviewed main commit is now the image publication approval. `hosted-image` retains its exact main-branch policy, captured reviewed source checks and isolated package-write job, with no required reviewers and no Azure OIDC permission. Only that named environment permits an absent reviewer rule; any present reviewer rule must have valid metadata, and malformed or duplicate rules fail closed. `hosted-production` still requires a distinct reviewer and self-review prevention for future CI Azure deployment. Azure deployment currently uses the owner's authenticated CLI rather than CI roles. This accepts publication without independent environment review while preserving deliberate dispatch and the separate production CI gate.
