# A short-lived desktop helper manages a versioned agent service

The Rust host maintains only the desktop's authenticated socket connection, while fixed `--ensure` and `--restart` invocations of the bundled agent manage service registration through the shared agent package. Keeping registration in TypeScript reuses its backup, trust and ownership rules without duplicating them in Rust. `runtime.json` identifies the agent by a SHA-256 hash of its bundled code, because a setup checkout revision does not identify the code shipped inside an app. A matching version and registration leave the service running; an upgrade or relocation waits for idle status and the shared apply lock, requests graceful shutdown, then rewrites and restarts registration while preserving policy, pauses and trust. Closing the window never invokes this helper or stops the service.
