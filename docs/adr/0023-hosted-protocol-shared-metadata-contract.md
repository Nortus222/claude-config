# Share a strict hosted metadata contract without moving local behavior

The hosted service and client need the same runtime checks without importing machine access or local IPC. `@nortuscc/hosted-protocol` owns strict HTTP v1 metadata schemas, policy literals and pure item and repository identity helpers; existing sync and agent exports re-export the shared definitions. Recursive unknown-field rejection and generic decode errors protect the metadata boundary, while engine-dependent `itemIdOf`, values, trust, classification, decisions, storage and `SetupSource` stay local. This avoids duplicating wire validation without making hosted metadata an authority for repository integrity or permission to apply, and preserves local Git fixture normalization separately from remote-only hosted URL validation.
