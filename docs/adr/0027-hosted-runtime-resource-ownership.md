# Own hosted runtime resources and use one managed identity endpoint

The embeddable metadata core cannot decide when credentials, recovery jobs or HTTP work stop. The production runtime now validates and recovers before listening, owns serial bounded recovery and request cancellation, and exposes readiness separately from strict v1 liveness. Production uses one ManagedIdentityCredential and one Strong Cosmos client at the configured endpoint, with endpoint discovery, background refresh and throttling retries disabled; this gives shutdown and failure deadlines predictable ownership, at the cost of automatic regional failover. A future failover policy must deliberately preserve those deadlines. Explicit literal-loopback emulator mode alone uses a dummy key. Cancellation may follow an already committed write, so existing CAS and durable recovery evidence remain authoritative, and ADR0025/0026 privacy and retention decisions are unchanged.
