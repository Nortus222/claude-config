# Fence deletion and reconcile independent publication checkpoints

Cosmos transactions stop at one partition, so setup reservations and publication heads commit separately from account checkpoints; sync repairs checkpoints, keeps decisions with their account sequence snapshot and hashes the complete response for conditional reads. Deletion freezes the account's setup and device-session indexes, closes and sweeps setup targets, deletes indexed sessions whose non-null versions fence delayed claims, and closes and sweeps the account before conditionally removing its GitHub identity; verified GitHub sign-in repairs the final closed-and-empty crash window after token hashes are gone. The owner approved retaining only opaque account/setup partition IDs, closed flags and concurrency versions permanently, a privacy tradeoff that prevents paused creators from resurrecting metadata without a cross-partition transaction; unbound device sessions have at most 900 seconds of validity, while persistent physical expiry remains an adapter requirement, not an implemented guarantee.
