# Keep app-owned routing outside portable instruction baselines

The desktop app's MCP connection guidance belongs to this machine, but whole-file instruction copying would erase it on apply or publish it on capture. Treat the two declared instruction files as a narrow copy exception: the machine StateStore retains a bounded, exact routing receipt, including separators and active or released intent, while config baselines and capture cover only the portable body. Shared locked operations back up the document and receipt before writes; edited, duplicate, foreign or invalid ownership blocks every force path. Retained released receipts also strip exact routing from historical originals during uninstall. This is local write bookkeeping, separate from profile preference layers, and costs shared config integration to keep reconciliation, capture and restoration consistent.
